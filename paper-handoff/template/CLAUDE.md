# AgentSkillsHack ICLR paper

Paper for **Agent Skill Firewall** (code: https://github.com/KuiyiGao/OpenClaw-Skill-Hack):
judging an agent skill by its runtime egress behaviour (egress proxy + canary,
five invariants, PASS / DEFER / BLOCK verdicts) rather than by static code.

## Layout (as on the Mac; keep it)

- `iterations/<YYYYMMDD>-r<NN>-<slug>/` — one folder per writing/experiment round,
  e.g. `20260924-r69-main-run-paper-r1/`. The newest folder is the live draft.
- Inside a round: LaTeX source, `figures/`, figure scripts, result fixtures, tests.
- `HANDOFF.md` — open tasks and state; read it first, update it last.

## Build

```bash
bash scripts/build.sh            # compiles the newest iteration's main .tex
bash scripts/build.sh path/to/main.tex
```
Cloud containers get tectonic + Python deps from the SessionStart hook
(`scripts/cloud_setup.sh`). CI (`build-pdf.yml`) compiles every push and uploads the PDF.

## Iteration protocol

1. Start a new round by copying the newest `iterations/` folder to the next `rNN`
   with a short slug; never edit an older round in place.
2. Change text, figures or experiments; rebuild; run the round's tests
   (`python -m pytest` inside the round if it has tests).
3. Append to the round's `CHANGELOG.md`: what changed, why, which reviewer
   point it answers. Update `HANDOFF.md`.
4. Commit per logical change and push. The PDF must compile before a push.

## Rules

- Numbers in the paper come from result files in the repo, never from memory.
  If a claim needs an experiment that has not been run, mark it `\todo{}` and
  list it in `HANDOFF.md`; do not invent results.
- Figures: Times font (match the ICLR template), vector PDF, generated by a script
  in the round, never hand-edited.
- Experiments that need API keys or GPUs run on the Mac or a configured machine;
  the cloud session writes the script and the expected-output schema, and records
  the command in `HANDOFF.md` under "needs a local run".
- Keep the anonymous submission anonymous: no names, repo URLs or acknowledgements
  in the submission build.
